# Data Directory

This directory contains input data, generated samples, and analysis outputs.

## Subdirectories

### `sample/`
Synthetic test videos generated by `scripts/generate_test_video.py`. These are deterministic, reproducible scenes used for testing and demonstration. Not real campus footage.

### `input/`
User-provided video or image files for analysis. Not tracked in git.

### `output/`
Pipeline output: annotated videos/images and JSON reports. Not tracked in git. Each run or API job writes to a subdirectory here.

### `uploads/`
Temporary storage for files uploaded via the web API. Not tracked in git. Cleaned up after processing.

## Notes

- Large files (videos, model weights) are excluded from git via `.gitignore`.
- Sample data is generated programmatically and can be recreated with `scripts/generate_test_video.py`.
- No real campus footage or personally identifiable imagery is included in this repository.
