## After Upload

Users will need to:

1. **Clone repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/campusnav-sentinel.git
   cd campusnav-sentinel
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   # YOLO model downloads automatically on first run
   ```

3. **Generate test data**
   ```bash
   python scripts/generate_test_video.py --output data/sample/test_campus.mp4 --duration 10
   ```

4. **Set API key** (optional)
   ```bash
   export NEBIUS_API_KEY=your_key_here
   ```

5. **Run application**
   ```bash
   PYTHONPATH=. python app/cli.py data/sample/test_campus.mp4 -o data/output
   ```
